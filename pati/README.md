# PATI · Gestión de Patinetas

Panel de administración web (Inicio, Inventario, Alquileres, Pagos, Usuarios, Mantenimiento, Configuración).

## Cómo abrirlo en Visual Studio Code
1. Descomprime la carpeta `pati`.
2. En VS Code: Archivo > Abrir carpeta... y elige `pati` (o abre `pati.code-workspace`).
3. Acepta instalar las extensiones recomendadas (Live Server y Prettier).
4. Clic derecho en `index.html` > "Open with Live Server".

También puedes abrir `index.html` directamente en el navegador.

## Archivos
- `index.html`: estructura de la página
- `styles.css`: colores y estilos (variables al inicio)
- `script.js`: datos de ejemplo, secciones y funcionalidad
